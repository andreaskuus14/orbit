## 4. Watch the update (about 10–15 min)

```
Get-Content C:\Users\andre\Documents\orbit\orbit-launcher.log -Wait -Tail 20
```

Good, in this order: `Building ORBIT into .next-build ...` → `Build finished; installing it.` → `New build installed ...` → `Update verified: <commit> answers, shows its pages and kept running for 2 minutes.`

Any line starting with `!!!!!` is a problem. The common ones:

| Line | Meaning | Do |
|---|---|---|
| `!!!!! UPDATE ROLLED BACK: ...` | The new version didn't pass its check; the old one is back and running. | Nothing to fix by hand. Send the line and the last 40 lines of `orbit-build.log` to the coordinator. Stop. |
| `!!!!! BUILD FAILED ...` | Build broke; the old version keeps running. | Send `orbit-build.log` (last 60 lines). Stop. |
| `!!!!! git pull failed ...` / `timed out` | No pull (local changes, no network, sign-in prompt). | Send `orbit-update.log`. Stop. |
| `!!!!! npm ci ...` | Dependencies failed; it goes back to the old commit. | Send `orbit-update.log`. Stop. |
| `!!!!! ORBIT runs, but: ...` | Running, but a setting or migration is missing (names only). | Note it; step 5 usually fixes the migration part. |

Check the running version: open http://127.0.0.1:3000/api/health. Its `commit` must equal `git rev-parse HEAD` in the repo.
